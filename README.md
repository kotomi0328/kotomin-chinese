# ことみんの中国語レッスン♡
ChatGPT に「kotomi0328/kotomin-chinese に第5課を追加して」と依頼すると、教材追加案を別ブランチに準備できます。GitHubへの書き込み手段（対応する接続またはログイン済みクラウドブラウザ）が必要です。公開はユーザー確認後に行います。

## 教材を追加する場所
lessons.js の lessons 配列に [課番号, 中国語, ピンイン, 日本語訳] を追記します。課のボタンと見出しは自動で増えます。第1〜4課の17文は元の内容・順序を保持しています。画面や音声コードの編集は不要です。

## 更新・検証手順
1. 最新mainと既存PRを確認し、別ブランチで教材を追記。
2. Node.jsで `node check.cjs` を実行。
3. 追加内容と確認結果をユーザーに提示。
4. 明示的な承認後にmainへ反映し、GitHub Pagesの更新を確認。

CSS・アイコン参照・音声/聞き流し処理の一致、既存教材、形式、課別表示、新課追加時の描画を自動チェックします。baseline.json は変更前の基準です。これはブラウザやiPhone音声エンジンそのもののテストではないため、実音声の品質・挙動は端末で確認してください。

この prepare-lesson-updates ブランチは準備用です。mainへのマージと公開はまだ行いません。
